# Guía de Instalación y Configuración - v1.2

## Requisitos del Sistema
- Android 8.0+ (API 26+)
- Permisos: GPS, Almacenamiento, Internet
- Espacio mínimo: 50MB

## Instalación
1. **App Principal**:
   - Descargar `laptimer-v12.apk`
   - Instalar en el dispositivo Android

2. **Panel Web (Pit Crew)**:
   - Desplegar el contenido de `pit-panel` en GitHub Pages o hosting estático
   - Configurar la URL de Firebase Realtime Database
